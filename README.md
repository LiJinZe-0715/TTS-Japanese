# VOICEVOX TTS

基于 [VOICEVOX CORE](https://github.com/VOICEVOX/voicevox_core) 的 Android 系统级日语语音合成引擎。

装好后可以在 **设置 → 无障碍 → 文字转语音** 中把它选为系统引擎。之后任何支持朗读的应用，
包括阅读器、浏览器和读屏软件，都能用 VOICEVOX 的角色声音念日语，用法和 Google TTS 一样。

## 特点

- **离线可用**：APK 内置日语词典和一个声音包（四国めたん、ずんだもん、春日部つむぎ、雨晴はう），装好就能朗读，不需要联网。
- **25 个声音包**：其余 24 个包在应用里按需下载，每个约 57 MB，下载后按官方发布的 SHA-256 校验。不需要的包可以随时删除。
- **每个角色都是系统 voice**：调用方可以像选 Google 的声音一样选角色。浏览器这类不选 voice 的应用会使用设置页里的「默认角色」。
- **边合成边播放**：长文本按句切分，后一句在前一句播放时提前合成，句与句之间没有停顿。
- **内存可控**：最多同时加载 2 个声音模型（每个约 234 MB），超出时卸载最久没用的那个。
- **随系统语言显示名字**：角色名和风格名在日文系统下显示日文原名，中文系统下显示中文译名，其他语言显示英文。切换系统语言不影响已选的默认角色。
- **设置页试听**：每个角色都能一键试听，还没下载的角色会先下载再播放。

## 系统要求

- Android 8.0（API 26）及以上
- 64 位 ARM 设备（`arm64-v8a`）
- 每加载一个声音模型约需 234 MB 内存

## 项目结构

按领域驱动设计分层，拆成三个 Gradle 模块，依赖方向为 `app → application → domain`：

| 模块 | 内容 |
|---|---|
| `domain` | 纯 Java：声音包与角色目录、名字翻译、文本切句、WAV 解析等领域模型和规则 |
| `application` | 纯 Java：朗读流水线、声音包管理、角色选择等用例，以及它们依赖的端口接口 |
| `app` | Android 应用：VOICEVOX CORE 的 JNI 封装、文件存储与下载（基础设施），系统 TTS 服务与设置页（表现层），以及装配 |

`domain` 和 `application` 不依赖 Android SDK，单元测试直接跑在普通 JVM 上。

## 音声利用

音声合成使用 VOICEVOX。使用各角色音声前，请阅读并遵守该角色及 VOICEVOX 的利用规约。
